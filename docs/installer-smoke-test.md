# VoxType 安装包冒烟测试清单

本清单用于在干净的 Windows 10 / Windows 11 虚拟机上验证 NSIS 安装包。与版本号无关，每次发布安装包后按同一套步骤执行。

发布前的代码检查由 `npm run ai:release-check` 覆盖；本清单覆盖的是它无法覆盖的部分：真实安装、WebView2 引导、首次启动、托盘与开机行为、更新入口和卸载。

## 执行前提

- 干净虚拟机：未装过 VoxType，`%LOCALAPPDATA%\VoxType`、`%APPDATA%\VoxType` 均不存在。
- 建议准备两台：一台 Windows 10 x64，一台 Windows 11 x64。其中至少一台不预装 WebView2 运行时，用于验证内嵌引导程序。
- 虚拟机需要有可用的麦克风（或虚拟声卡）和网络。
- 准备一份**测试用**的 ASR 凭据。不要使用日常主力账号的密钥，测试后在服务商控制台吊销。

## 证据字段

每次执行记录以下字段，填进发布审计或 Issue：

| 字段 | 示例 |
| --- | --- |
| Windows 版本 | `Windows 11 Pro 26200` |
| 安装包文件名 | `VoxType_0.13.1_x64-setup.exe` |
| 安装包 SHA-256 | `certutil -hashfile 安装包路径 SHA256` 的输出 |
| WebView2 预装状态 | 预装 / 未预装（由内嵌引导安装） |
| 结果 | 通过 / 失败（附失败步骤编号） |
| 执行人与日期 | |

## 隐私规则

记录证据时**不得**包含：真实密钥、识别正文、热词、提示词、最近上下文、屏幕 OCR 文本、原始日志、统计文件，以及含 Windows 用户名的完整路径。路径一律写成 `%LOCALAPPDATA%\VoxType\...` 形式。

截图前先关闭含个人信息的窗口；设置页截图必须保持密钥为隐藏状态。

## 检查项

### 1. 安装

| # | 步骤 | 预期结果 |
| --- | --- | --- |
| 1.1 | 核对安装包 SHA-256 与 Release 说明一致 | 完全一致；不一致立即停止并重新下载 |
| 1.2 | 双击安装包 | SmartScreen 可能提示未签名，属已知情况；确认后可继续 |
| 1.3 | 完成安装向导 | 安装到 `%LOCALAPPDATA%\VoxType`，不要求管理员权限 |
| 1.4 | 未预装 WebView2 的机器上观察安装过程 | 内嵌引导程序自动安装 WebView2，无需手工干预 |
| 1.5 | 查看开始菜单 | 存在 VoxType 快捷方式 |

### 2. 首次启动（无 `config.toml`）

| # | 步骤 | 预期结果 |
| --- | --- | --- |
| 2.1 | 从开始菜单启动 | 主窗口打开，不崩溃、不白屏 |
| 2.2 | 观察首页状态 | 明确提示未配置语音识别认证信息，并给出前往 API 配置页的入口 |
| 2.3 | 打开 API 配置页 | 豆包接入方式默认为「语音控制台 API Key（推荐）」，密钥输入框为空 |
| 2.4 | 不填任何内容直接按主快捷键 | 不开始录音，给出可读的未配置提示，不出现堆栈或内部路径 |
| 2.5 | 打开配置指南入口 | 浏览器打开对应文档页面 |

### 3. 保守默认值

| # | 步骤 | 预期结果 |
| --- | --- | --- |
| 3.1 | 查看选项页启动方式 | 主快捷键开启；**右 Alt 和鼠标中键均为关闭** |
| 3.2 | 查看最近上下文开关 | 关闭 |
| 3.3 | 查看录音期间静音系统声音 | 关闭 |
| 3.4 | 查看开机自启动 | 关闭 |
| 3.5 | 查看大模型润色 | 关闭或未配置，不因未配置而阻断主流程 |

任何一项默认开启都算失败：这些是项目明确不可回退的保守默认值。

### 4. 配置与识别冒烟

| # | 步骤 | 预期结果 |
| --- | --- | --- |
| 4.1 | 在 API 配置页填入测试凭据并保存 | 保存成功，密钥默认隐藏 |
| 4.2 | 点击「测试语音识别连接」 | 返回成功。该测试只发送程序生成的静音包，不打开麦克风 |
| 4.3 | 回到首页确认状态 | 显示为可用状态 |
| 4.4 | 在记事本中按主快捷键说一句话 | 悬浮字幕出现实时文字；停止后文本粘贴到光标处 |
| 4.5 | 按下后立即停止，不说话 | 进入失败态并给出提示，**不得**显示「已粘贴」或计入成功统计 |
| 4.6 | 查看统计页 | 只显示时长、字数、速度等非正文数据 |

### 5. 托盘与窗口行为

| # | 步骤 | 预期结果 |
| --- | --- | --- |
| 5.1 | 关闭主窗口 | 按设置最小化到托盘或退出，首次关闭有一次性说明 |
| 5.2 | 托盘图标右键菜单 | 菜单项可用，语言与当前设置一致 |
| 5.3 | 从托盘重新打开主窗口 | 正常恢复，状态未丢失 |

### 6. 更新入口

| # | 步骤 | 预期结果 |
| --- | --- | --- |
| 6.1 | 启动后查看更新检查 | 已是最新版本时明确提示「已是最新」，不弹安装流程 |
| 6.2 | 安装比线上 Release 更旧的版本再启动 | 提示有新版本可用，并显示目标版本号与安装包名 |
| 6.3 | 触发下载安装 | 下载后静默启动安装程序并完成升级；升级后配置与统计保留 |

### 7. 卸载

| # | 步骤 | 预期结果 |
| --- | --- | --- |
| 7.1 | 从「应用和功能」卸载 | 卸载完成，`%LOCALAPPDATA%\VoxType` 下的程序文件被移除 |
| 7.2 | 检查用户数据 | `%APPDATA%\VoxType\config.toml` 等用户数据**保留**，不被静默删除 |
| 7.3 | 重新安装后启动 | 沿用原有配置，不要求重新填写凭据 |
| 7.4 | 手工清理用户数据后启动 | 回到第 2 节的首次启动状态 |

### 8. 收尾

- 在服务商控制台吊销测试用凭据。
- 删除或重置虚拟机快照，避免测试凭据和日志残留。

## 失败如何上报

任一步骤失败时，按仓库的 Bug 模板开 Issue，包含：步骤编号、Windows 版本、安装包文件名与 SHA-256、WebView2 预装状态、实际现象、以及**脱敏后**的最小复现步骤。

不要附带原始日志文件。需要日志片段时只摘录相关行，并把用户名路径替换为 `%LOCALAPPDATA%` 形式。

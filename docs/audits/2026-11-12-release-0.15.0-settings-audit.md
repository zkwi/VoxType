# VoxType 0.15.0 发布审计

## 版本与设计

本次使用 minor 版本。托盘可直接恢复主窗口，缺少 ASR 配置时会进入 API 配置页。麦克风启动失败沿用录音中断的 1.8 秒错误窗口，并用会话 generation 避免旧计时器关闭新一轮的字幕。

常用设置集中在选项页。主快捷键可独立启停，录制有效组合后才保存，按 Esc、移开焦点或切页会退出录制。设备刷新复用健康检查的设备枚举，录音静音使用现有系统音量设置。系统提示词和豆包资源规格分别置于提示词和 ASR 高级设置。标准接入可选小时版或并发版，已有其他资源 ID 会显示为当前值。

主窗口处理更新、统计、设备和配置。字幕窗口只订阅会话、电平、字幕和外观事件，并通过同源语言设置更新当前状态文案。配置字段与默认策略沿用现有定义。ASR 最终包门禁、音频分片、OCR 等待、尾音和剪贴板输出沿用原有流程。

## 依赖审计

发布预检在原锁文件发现已公开的依赖问题。前端更新 SvelteKit、静态适配器、Vite 和 Vitest，按 [SvelteKit 3 迁移指南](https://svelte.dev/docs/kit/migrating-to-sveltekit-3) 将静态构建配置迁到 Vite。Rust 锁文件更新 `quinn-proto`、`rustls`、`rustls-webpki` 和 `webpki-roots`。

npm 审计对开发依赖 `deepmerge@4.3.1` 中尚无上游补丁的 [GHSA-gcqx-w48m-w2h4](https://github.com/advisories/GHSA-gcqx-w48m-w2h4) 保留单项例外。Vite 的 Svelte 插件用它合并仓库的构建配置，桌面应用运行时不使用它。其他公告仍由发布门禁拦截。

## 已验证

- 本地 `npm run ai:release-check` 通过。74 个前端单测和 288 个 Rust 单测通过，2 个真实剪贴板用例按设计忽略。Rust 依赖审计保留既有例外，并报告 8 条允许告警。NSIS x64 安装包构建通过。
- 使用独立 Windows 调试实例和临时配置，逐一验证四种 ASR 认证缺失时，真实全局快捷键从隐藏状态唤回 API 配置。验证字幕窗口三语切换、启动请求范围、快捷键录制和取消、麦克风刷新及健康状态 IPC、静音开关保存、系统提示词保存、豆包资源规格保存和认证错误清除。检查桌面和 390px 宽度的麦克风设置。

## 手工回归

- 将未配置语音服务的实例隐藏到托盘，使用录音快捷键，确认主窗口进入 API 配置。分别检查豆包语音控制台 API Key、旧版 App Key、Agent Plan 和阿里云 FunASR。
- 在无可用麦克风的测试环境触发录音，确认悬浮窗提示约 1.8 秒后消失。恢复设备后立即重试，确认旧错误计时不会隐藏新字幕。
- 切换界面语言并确认当前悬浮窗状态文案即时更新。托盘右键打开主窗口并手动检查更新一次。
- 连接外置麦克风后刷新设备，核对列表和健康状态。用临时配置测试主快捷键、录音时静音、豆包资源规格和系统提示词保存。

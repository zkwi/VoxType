# VoxType 0.19.0 发布审计

此页记录 0.19.0 当时的行为。托盘预览和等待音柱的后续调整见 [0.19.1 发布审计](2026-11-12-release-0.19.1-tray-preview-audit.md)。

## 版本与范围

0.18.0 已正式发布并包含设置重排。润色跳过、风格预设、原文恢复和字幕动效改变了日常体验，因此按 minor 发布 0.19.0。风格预设写入原有两个提示词字段，正式成稿对应原默认值。

- 润色请求检测长度截断和明显缩水，异常时保留最终识别原文。只有输出发生变化且主窗口可见时才发送额外的原文预览。
- 同一会话内的润色跳过与粘贴切换共用代际锁。跳过只使用已收到的最终包。剪贴板恢复警告单独传递，不会重建已清空的预览。
- 字幕采用无描边圆角，并关闭 Windows 无边框窗口的原生阴影。文字原位更新，等待和润色阶段使用静态样式。粘贴键发出后异步淡出一次，由会话代际和字幕窗修订号共同保护。
- ASR 分片、OCR 等待、尾音、热键钩子和剪贴板恢复机制沿用既有实现。

## 验证

- Rust 用例覆盖截断、明显缩水、代码围栏、过期代际与粘贴时的跳过标记。前端用例覆盖连续电平和预设匹配。
- 润色输出路径已完成一次只读独立复审。已修复空结果边界、后置告警重建预览以及旧会话关闭新字幕窗的问题。
- 使用本机模拟 ASR、LLM 和隔离输出验证短句直出、截断回退、润色跳过、原文复制载荷、隐藏清理与跨轮字幕。Windows 粘贴冒烟确认发出按键，测试输入框未收到输入。
- 在原生字幕窗的 WebView2 中，对收尾与润色各采样超过 3 秒，卡片透明度稳定且无循环动画。字幕更新复用文本节点，收起仅执行一次 140ms 淡出。
- 发布门禁采用 `npm run ai:release-check`、GitHub Actions 和 Windows NSIS 安装包校验。

## 手工回归

1. 在启用润色的配置下分别听写低于和高于阈值的句子。确认短句直出，长句在服务等待时显示润色状态。
2. 润色期间再按一次已启用的触发键，确认直接输出最终识别原文。粘贴后立即开始新一轮，确认新字幕仍可见。
3. 成功润色后在首页展开对照并复制原文，隐藏窗口后重新打开，确认预览已清除。
4. 在系统中切换减弱动画，并验证最小主窗口、单行与双行字幕以及常用配色。

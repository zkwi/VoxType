# VoxType 0.21.0 发布审计

日期：2026-11-21

## 版本判断

本次从 `0.20.1` 升级至 `0.21.0`（minor 递增）。改动引入了多模态大模型截图润色能力并调整了默认屏幕参考策略（`screen_context.llm_mode = "screenshot"`，同时保留 `"ocr"` 选项），新增设置项、设置测试图预览、首页/隐私动态口径与纯文本模型自动 OCR 回退链路，并同步三语言界面文案、配置模板与 Wiki 指南，属于显著的用户可见功能与默认策略升级。

## 改动范围

- **多模态屏幕截图采集与压缩（`screen_context.rs`、`config.rs`、`config_validation.rs`）**：
  - 新增 `screen_context.llm_mode`（默认 `"screenshot"`，可选 `"ocr"`），校验仅允许这两个值。
  - 开始录音时继续只抓取一次屏幕并通过 `Arc` 共享帧数据，由 Windows OCR（ASR 与兜底）与 WinRT 并行图像编码共同复用；图像保持长边不超过 `1600px`、JPEG 质量 `0.80`（未缩放且体积更小时保留 PNG）、总量上限 `1.5 MB`（超限时自动降级质量 `0.65` / `1200px` 并再次校验上限，超限则返回错误让润色阶段 cleanly 回退 OCR）。
  - GDI `BitBlt` 位图转换显式使用 `BitmapAlphaMode::Ignore` 避免全透明伪影；`PendingScreenContext::resolve_for_post_edit()` 通过非阻塞 `try_recv()` 取用本轮截图或 OCR，不改变 ASR `200ms` 分片与 `500ms` OCR 等待窗口。
- **大模型多模态请求、能力探测与 OCR 自动兜底（`llm_client.rs`、`llm_request_adapter.rs`、`llm_post_edit.rs`、`asr_ws/worker.rs`）**：
  - 支持 OpenAI 兼容 `text + image_url` 多模态请求体；推理预算扩容与思考参数兼容重试完整保留本轮图像。
  - `/models` 能力探测解析并缓存模型视觉支持标记；遇到仅支持文本模型或图像输入报错时（使用状态码前缀解析，避免 JSON 业务编号误判），自动改用 OCR 文本重试一次且进程内记住该模型，首轮发出 `LLM_VISION_FALLBACK_OCR` 温和提示并保留 `raw_text` 对照。
  - 更新默认 `system_prompt` 与前端润色预设，引导模型结合屏幕画面（含界面高亮选中项与代码符号）纠正原文而不描述图片内容。
- **设置交互、预览、隐私展示与诊断脱敏（`HotwordsSection.svelte`、`ApiConfigSection.svelte`、`HomeSection.svelte`、`PrivacySection.svelte`、`PromptPreviewDialog.svelte`、`settingsNavigationController.svelte.ts`、三语言 i18n）**：
  - 「词库与上下文 → 屏幕上下文」新增大模型参考方式选择、未配置润色时的快捷提示与跳转按钮、以及压缩截图体积/分辨率与 OCR 同框预览。
  - 「语音与润色服务」新增屏幕参考联动状态栏与跳转入口；「首页速览」「最终提示词预览」「隐私与本地数据」随模式实时联动；`diagnostics` / `app_log` 与自定义 `Debug` 实现严格脱敏（不输出 base64 图像数据、OCR 原文、提示词、热词、正文或 Windows 用户名路径）。
- **多轮审计与 UI 打磨**：
  - **第一轮代码/并发/隐私 Diff 审计**：修正 `is_unsupported_image_error` 原始数字子串匹配漏洞、压缩降级后分辨率赋值顺序与 `1.5 MB` 严格拒绝、内联按钮作用域样式问题，以及为 `ScreenContextSnapshot` / `PostEditScreenContext` / `ScreenContextTestResult` 补充脱敏 `Debug` 实现与单测。
  - **第二轮真实浏览器 UI/UX 审计**：在桌面（`1280×800`）与窄窗口（`960×640`）跨简体中文 / 繁體中文 / English 实测，修复跨页跳至 `#settings-screen-context` 被粘性导航栏遮挡、跳转首项文案过长折行、提示词预览弹窗水平滚动条、隐私表窄列单字折行以及「页页」错字，复测 0 console/network 错误通过。
  - **第三轮文档、治理与发布前审查**：同步 `config.example.toml`、中英文 `README`、架构/守门文档及 `docs/wiki/*.md`，完成发布预检、正式安装包构建与终轮只读 diff 复核。

## 手工回归建议

1. 保持默认「直接发送压缩截图」模式，在代码编辑器或带蓝色高亮选中项的界面中按 `Ctrl + Q` 口述人名/文件名/代码符号，确认能结合画面准确输出且日志不记录截图或 OCR 正文。
2. 在「词库与上下文 → 屏幕上下文」点击「立即测试截取」，确认同框展示截图尺寸/体积与本地 OCR 结果；隐藏窗口或重新触发录音后确认预览清空。
3. 切换至纯文本大模型，确认首轮触发温和回退提示并使用 OCR 兜底、后续轮次跳过图片上传；再切换回支持视觉的多模态模型或 `ocr` 模式确认工作正常。

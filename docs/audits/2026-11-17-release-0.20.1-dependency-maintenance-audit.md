# VoxType 0.20.1 发布审计

日期：2026-11-17

## 版本判断

本次从 `0.20.0` 升级至 `0.20.1`（patch 递增）。改动源自合并 GitHub 上全部未合并的 Dependabot 维护分支（PR `#89`、`#90`、`#91`、`#92`），同步了 Tauri 运行时插件、前端打包构建工具以及 CI / CodeQL 工作流依赖，无新增功能或主链路行为变更，按规则递增 patch 版本。

## 改动范围

- **Tauri 与前端依赖更新**：升级 `@tauri-apps/api`（`2.12.4`）、`@tauri-apps/cli`（`2.12.4`）、`@tauri-apps/plugin-opener`（`2.7.3`）、Rust crate `tauri-plugin-opener`（`2.7.3`）以及前端构建工具 `vite`（`8.3.8`）。
- **CI 工作流维护**：升级 `.github/workflows/ci.yml` 中 `taiki-e/install-action` 至 `v2.90.3`，升级 `.github/workflows/codeql.yml` 中 `github/codeql-action/init` 与 `analyze` 至 `v4.39.3`。
- **主链路与隐私边界**：未改动录音采集、ASR 流式识别、大模型思考档位适配与润色、悬浮字幕、剪贴板输出、非正文统计及日志脱敏逻辑；配置文件格式无变更。

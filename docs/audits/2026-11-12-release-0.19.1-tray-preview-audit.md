# VoxType 0.19.1 发布审计

## 版本与范围

0.19.1 是托盘原文预览和悬浮字幕反馈的补丁版本。后台完成的润色结果会投递到主窗口内存。润色改变输出且没有润色告警时，同一事件携带经过句尾标点处理的原文。再次隐藏、开始下一轮、手动清空或退出会清除预览。

等待最终包和润色时，仅四根音柱按错开的节奏缩放。字幕文字、卡片背景、透明度和无白边样式沿用 0.19.0。系统减弱动画时音柱静止，正常输出后的单次淡出沿用既有代际保护。

## 验证

- 定向用例覆盖有改动、有告警、无改动、空输出、句尾标点开关和下一轮会话清理。
- 原文交付和清理完成一次独立复审。结果在主线程投递前核对隐藏修订号与会话代次，重复隐藏已在托盘的窗口不会再次清除结果。
- 发布前使用 `npm run ai:release-check`，并在隔离的 Windows WebView2 中回归托盘完成、重新打开、再次隐藏及音柱样式。

## 手工回归

1. 隐藏主窗口到托盘，完成一轮会改变文本的润色，打开主窗口并确认可查看和复制原文。
2. 再次隐藏并打开，确认两份文本预览均清除。重做一轮后开始下一次录音，确认旧预览清除。
3. 在等待最终包和润色期间观察字幕，确认只有内部四根音柱起伏。切换系统减弱动画后确认音柱静止。

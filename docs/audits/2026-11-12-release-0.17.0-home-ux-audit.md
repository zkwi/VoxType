# VoxType 0.17.0 发布审计

## 版本与范围

0.16.0 已正式发布。本轮改进了首页布局、设置导航、快捷键录制和使用统计展示，按可见体验改进递增 minor。版本号同步到 npm、Cargo 和 Tauri 元数据。

- 首页从触发方式、麦克风状态和配置速览直达对应设置。配置健康检查的「粘贴方式」跳转到输出设置。识别完成后可依次查看、复制或清空文本。
- 主快捷键录制期间，右 Ctrl、右 Alt 和鼠标中键暂时放行。录制完成、取消、失焦或隐藏主窗口后恢复。已放行的按下事件对应的松开事件仍会放行，避免在录制结束时误触发。
- 累计统计从现有 JSONL 的全部有效事件计算。近 7 日卡片显示次数和时长，历史窗口和最近记录保持原口径，统计文件沿用原格式。
- 合入 #79 的 GitHub Actions、#74 的 Tauri、#83 的 Rust 依赖和 #78 的前端依赖。Tauri 2.12.2 继续使用 `tray-icon 0.25.1`，托盘窗口类和离开定时器仍在现有兼容范围。

## 验证

- Rust 回归用例覆盖右 Ctrl、右 Alt 和中键在录制期间按下、退出后松开及下一次触发，也覆盖超出 7 日窗口和 30 条明细上限的累计统计。
- 累计统计完成一次只读独立复审。已调整英文文案，使单条记录也能正确显示。
- 在隔离 Windows WebView2 实例中，以 1280px、960 × 640 和 390px 验证首页渲染。桌面胶囊单行，窄屏胶囊自然换行，速览为两列。验证了麦克风、触发设置、配置速览、健康检查、统计明细导航和完成态按钮顺序。中英文截图取自合成统计样本。
- 发布门禁采用 `npm run ai:release-check` 和受保护主分支的 GitHub Actions 检查。Windows x64 安装包通过 NSIS 构建，发布时校验 SHA-256。

## 手工回归

1. 在 1280px 和最小窗口 `960 × 640` 下打开首页。点击麦克风、主快捷键和任一备用胶囊，确认设置定位和备用面板展开。切换到 API 配置的健康检查，点击「粘贴方式」确认进入输出设置。
2. 在待命态检查配置速览和统计明细入口。用早于 7 日的本地记录确认累计次数和字数包含该记录，近 7 日数据只包含窗口内的记录。
3. 在测试环境启用右 Ctrl。点击主快捷键录制框，用物理键盘按下右 Ctrl + K 并松开，确认录制为 Ctrl + K 且未启动录音。退出录制后单按右 Ctrl，确认恢复录音触发。
4. 用有效 ASR 配置完成一次真实听写，检查最终输出以及首页查看、复制和清空按钮。安装升级时核对程序版本和已有配置、统计文件。

# VoxType 0.18.0 发布审计

## 版本与范围

0.18.0 是设置体验的 minor 更新。三语侧栏及页内跳转按日常使用顺序排列，现有 ASR、LLM、录音、剪贴板与统计逻辑沿用原行为。配置键名、默认值和序列化格式沿用 0.17.0。

- 语音与润色服务页的健康检查在就绪时折叠，可展开或重新检查。最小润色字数移至大模型润色面板。
- 词库与上下文集中放置手动热词、自动候选、屏幕 OCR、场景和提示词。OCR 字数上限使用既有的 `screen_context.max_chars`，识别范围及测试预览沿用既有绑定。
- 常规与快捷键包含输入链路和界面系统两组。补齐启动与窗口锚点，增加界面语言入口。首页录音质量提示可直达展开的排障面板。

## 验证

- 路由单测覆盖 OCR、最小润色字数、手动热词与录音排障字段。发布门禁采用 `npm run ai:release-check` 和 GitHub Actions。
- 在隔离的 Windows WebView2 实例中验证就绪与未就绪的健康检查、六页切换和跨页设置跳转，覆盖 1280px、960 × 640 和 390px。读取并修改旧格式配置的润色阈值和 OCR 字数上限，确认无效值未落盘，撤回到已保存值后错误提示消失。OCR 预览测试使用合成结果，截图使用合成统计和测试配置。
- 安装包采用 Windows x64 NSIS。发布与本机升级校验安装包 SHA-256，升级前后核对程序版本和本地配置、统计文件。

## 手工回归

1. 在语音与润色服务页展开检查详情，点击粘贴方式并确认落在输入结果面板。用未配置的测试配置打开该页，确认首次引导和阻断项可见。
2. 从首页打开大模型润色和词库与上下文。修改最小润色字数和 OCR 字数上限，确认值能保存并在返回页面后读回。
3. 点击词库与上下文页的提示词锚点，确认编辑区展开。从首页录音质量提示进入录音排障，确认可直接看到输入增益与无反馈自动停止字段。
4. 在启动与窗口切换界面语言，确认侧栏同步。升级后用现有设置完成一次听写。

# VoxType 0.20.0 发布审计

日期：2026-11-17

## 版本判断

本次从 `0.19.1` 升级至 `0.20.0`（minor 递增）。改动新增了基于 `/v1/models` 能力声明的思考档位自动适配、通用网关 `reasoning_effort` 支持、手动档位保留语义、连通测试截断自动提额重试与推理模型润色输出余量，并同步更新了三语言设置文案与配置文档，属于用户可见功能与适配行为优化。

## 改动范围

- **端点与模型能力探测**：新增 `models_endpoint` 归一化与 `fetch_models_payload`，在保存/切换模型自动适配及 `auto` 直跑润色（2 秒上限缓存探测）时优先解析 `/v1/models` 声明的最低可用档位（`none` / `minimal` / `low`），仅使用进程内内存缓存；未声明时回退既有服务商兼容探测，无 `config.toml` 字段变更。
- **通用 `reasoning_effort` 与手选保留**：通用 OpenAI 兼容网关通过顶层 `reasoning_effort` 发送 `none`、`minimal` 和 `low`，OpenRouter 继续沿用嵌套 `reasoning` 对象；后端手选非 `auto` 策略不再被重写或剥离，前端 `llmAutoAdaptController` 区分“切换模型（恢复 `auto`）”与“高级设置手选（保留手选档位）”。
- **测试截断重试与输出余量**：连通测试要求非空正文且未被 `length`/`max_tokens` 截断；首次 `256` token 截断后保持原档位（无能力声明的非 DashScope 网关优先 `openrouter_reasoning_low`）按 `768` token 重试一次。正式润色与自动热词候选生成同步复用能力探测结果，对开启思考或仍产生推理 token 的策略/模型增加 `1,024` token 余量（润色分档 `1312 / 1664 / 2304 / 3072`，热词生成封顶 `6,000`），若仍截断则继续回退完整识别原文或保持原有错误处理。
- **关联体验与单测修复**：连接测试成功保存策略后提示展示本地化策略名称而非内部枚举值；`test_llm_config` 全部连接测试错误分支统一返回 `LLM_TEST_*` 错误码并在前端映射简体中文 / 繁體中文 / English 三语言文案；`vite.config.js` 将 `src/lib/app/**/*.test.ts` 纳入 `npm run test:unit` 执行范围，一并覆盖已有 `sessionController.test.ts` 与新增 `llmAutoAdaptController.test.ts`、`userFacingErrors.test.ts`。
- **传递依赖安全更新**：更新 `Cargo.lock` 中 `quinn-proto`（`0.11.19`）与 `quinn-udp`（`0.5.16`）补丁版本，消除上游 `RUSTSEC-2026-0523`、`RUSTSEC-2026-0524` 和 `RUSTSEC-2026-0538` 依赖审计告警，不修改 `Cargo.toml`。
- **主链路与隐私边界**：不修改录音、ASR 最终包门禁、悬浮字幕规则、剪贴板输出与恢复、非正文统计及日志脱敏口径；日志仅记录模型名、策略、预算与脱敏状态，不记录密钥、提示词、测试文本或识别正文。

- **Rust 单元测试与本地模拟网关测试**：`cargo test llm_`（51 项）与全量 `cargo test`（307 passed，2 项手工剪贴板测试默认 ignored）全部通过，覆盖 `/models` 端点归一化、Magpie/OpenRouter 能力解析与缓存、非 OpenRouter 顶层 `reasoning_effort` 格式、手选 `low` 保留，以及基于 `std::net::TcpListener` 模拟网关的 4 组端到端测试（`none` 档位 `256/288`、`low` 档位 `256 -> 768` 重试与 `1,312` 润色余量、`/v1/models` 404 回退、手选 `low` 全程保留）。
- **前端单元测试与治理检查**：`npm run test:unit`（20 个测试文件、97 项测试）、`npm run check:governance`、`npm run scan:secrets` 均通过；`llmAutoAdaptController.test.ts` 验证模型切换、手选保留、手动测试与策略名称映射，`userFacingErrors.test.ts` 验证三语言错误码映射与不安全载荷过滤。

## 手工回归建议

1. 使用提供 `/v1/models` 能力声明的网关切换不思考模型（如 DeepSeek Flash）与最低 `low` 思考模型（如 Hydrogen / Kimi K3.1 Pro），观察自动适配是否在提示中保存对应策略并顺利通过连接测试。
2. 在「语音与润色服务 → 高级兼容性设置」手动选择 `reasoning_effort=low（低思考强度）`，确认保存与点击测试后策略不被改回，短句和长句正式润色可完整返回。
3. 随后切换到另一个模型，确认自动适配恢复按新模型重新探测；复测 DashScope、DeepSeek 官方直连，确认既有行为无回退。
